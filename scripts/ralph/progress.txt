## Codebase Patterns
- Scripts use relative imports (`../src/lib/schemas`) NOT `~/` aliases — tsx resolves tsconfig paths but relative is more reliable in script context
- data/*.json is in .gitignore; scripts call mkdirSync("./data", { recursive: true }) to ensure the directory exists at runtime
- Item type lives in src/types/item.ts; standalone Move type in src/types/move.ts (separate from LearnableMove in pokemon.ts)
- itemSchema and moveSchema exported from src/lib/schemas.ts; itemCategorySchema and moveCategorySchema are local const reuse within the file
- DB client: @libsql/client with `file:./data/cobblemon.db` for local dev — no auth token needed for file: URLs
- Schema applied by splitting schema.sql on `;` and executing each statement; INSERT OR REPLACE used for idempotent seeding
- Nested data (types, baseStats, abilities, moves, etc.) stored as JSON strings in SQLite TEXT columns
- Scripts exit gracefully (code 0) when datapack isn't present — produce empty valid JSON arrays
- React Router v7 framework mode (SPA): requires `ssr: false` in react-router.config.ts and `@react-router/node` package
- tsconfig MUST include `"rootDirs": [".", "./.react-router/types"]` for generated types to resolve
- tsconfig needs `"allowImportingTsExtensions": true` and `"noEmit": true` in bundler/RR7 mode
- Tailwind v4 setup: use `@tailwindcss/vite` plugin + `@import "tailwindcss"` in CSS (no tailwind.config.ts needed)
- Route files use `$param` convention (not `[param]`): `$id.tsx`, `$slug.tsx`
- App directory is `src/app` (configured in react-router.config.ts), routes in `src/app/routes/`
- `src/app/routes.ts` file required — use `index()` and `route()` helpers from `@react-router/dev/routes` (no `flatRoutes`)
- `~/*` path alias maps to `./src/*` via tsconfig paths
- Types in `src/types/` (pokemon.ts, spawn.ts, team.ts); Zod schemas in `src/lib/schemas.ts`; constants in `src/lib/constants.ts`
- Zod enums from const arrays: cast with `as [string, ...string[]]` then further cast to `z.ZodEnum<[...]>` for type safety
- PokemonType tuple `[PokemonType] | [PokemonType, PokemonType]` — use `z.union([z.tuple([...]), z.tuple([..., ...])])`
- Hono server uses `@hono/node-server` serve() for tsx/Node; route order matters — specific paths (/search) before params (/:id)
- SQLite TEXT columns (types, base_stats, etc.) stored as JSON strings — parse with JSON.parse() in row-mapping helpers
