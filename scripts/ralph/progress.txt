## Codebase Patterns
- JSON output files use `{ _meta: { datapackVersion: '1.7.3+1.21.1', generatedAt: '...' }, data: [...] }` format. All readers must handle both the old array format and the new object format (check `Array.isArray`).
- `seed-db.ts` calls extract-pokemon.ts, extract-spawns.ts, extract-items.ts via spawnSync before seeding — data always comes from the canonical datapack, not manually-edited files.
- DB tables (pokemon, spawn_entries, items, moves) have a `source_file TEXT` column for traceability.
- Extract scripts use COBBLEMON_DATAPACK_PATH env var (default: `./data/datapack`).
- `extract-moves.ts` fetches from PokeAPI — do NOT call from seed automatically (network may be unavailable; it has its own caching).
- TypeScript typecheck: `npm run typecheck` (tsc --noEmit). Uses strict mode with noUnusedLocals/Parameters.
- `esbuild` in node_modules may be platform-specific (macOS vs Linux); run `npm install --platform=linux --arch=arm64 esbuild` if needed in Linux container.
- Spawn conditions use `minSkyLight`/`maxSkyLight` (not `minLight`/`maxLight`) — matches raw datapack field names.
- `neededNearbyBlocks` in spawn files can be either `string[]` or `Array<{blocks: string[], range?: number}>` — always handle both formats.
- `spawn_entries` table has a `weight_multiplier TEXT` column (JSON) for conditional weight multipliers.
