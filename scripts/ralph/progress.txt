## Codebase Patterns
- Pokémon detail route ($id.tsx): uses useEffect([id]) to reset form/tab state on navigation; inline <style> tag for keyframes since Tailwind v4 can't generate arbitrary animation classes; type-adaptive glow via `rgb(var(--type-${primaryType}) / 0.X)` in inline styles
- server GET /api/pokemon/:id returns prevId/nextId via: `SELECT id FROM pokemon WHERE dex_number < ? ORDER BY dex_number DESC LIMIT 1` and `dex_number > ? ORDER BY dex_number ASC LIMIT 1`
- EvolutionChain component receives pokemonName + evolutions[] (what current evolves INTO); full pre-evo chain not available from single API call
- Pokemon detail types extend the base Pokemon interface: `interface PokemonDetail extends Pokemon { spawns: unknown[]; prevId: string | null; nextId: string | null }`
- Filter state in URL via useSearchParams (react-router): encode arrays as comma-joined strings (?types=fire,water), delete key when empty, use { replace: true } to avoid polluting history
- Client-side filtering with applyPokedexFilters(): fetch all 1000 rows once, filter in useMemo — avoids round-trips for facet changes
- FilterSheet built from @radix-ui/react-dialog primitives (no shadcn CLI needed); same pattern as Sheet component in layout
- Server primaryContext/primaryWeather: correlated subqueries using CASE WHEN json_extract(conditions,'$.isThundering') for weather detection
- TanStack Virtual v3: `rowVirtualizer.measureElement` is a ref callback — place on DOM elements with `data-index={virtualRow.index}`; padding rows approach (spacer `<tr>`) for tables; absolute-positioned items for card lists
- For table virtualization: `paddingTop = virtualItems[0]?.start ?? 0`; `paddingBottom = totalSize - (lastItem?.end ?? totalSize)` — add as spacer rows with `height` style
- For mobile card virtualization: use `position: "relative"` container with `height: totalVirtualSize + offset`, items use `position: "absolute", transform: translateY(start + topPadding)`
- `useIsMobile()` pattern: useState initialized from `window.innerWidth < 768`, updated via `matchMedia("(max-width: 767px)").addEventListener("change", handler)`
- TanStack Table v8: `createColumnHelper<T>()` for typed columns; `.display({id, header, cell, enableSorting, size})` for computed columns; `.accessor(key, {header, cell, sortingFn, size})` for data columns; `getSortedRowModel()` needed for client-side sorting
- Server list endpoint (`GET /api/pokemon`): limit max bumped to 1000; now returns `base_stats`, `primaryBucket`, `primaryBiomes` (via correlated subqueries on spawn_entries); BST computed client-side from baseStats fields
- WHERE conditions in list query use unqualified column names — safe with table alias `p` since SQLite resolves without ambiguity when single table in FROM
- TanStack Query: QueryClient created at module scope in root.tsx; QueryClientProvider wraps the `<Outlet />` in the `App` export (not `Layout`) — available to all routes
- cmdk v1.0.0 uses named exports: `import { Command, CommandInput, CommandList, CommandGroup, CommandItem, CommandEmpty, CommandLoading, CommandSeparator } from "cmdk"` — NOT dot-notation sub-components
- Command palette pattern: use `shouldFilter={false}` when doing server-side filtering; prefix item values (`pokemon-{id}`, `history-{id}`, `action-{id}`) to distinguish types in `onValueChange`
- API calls from frontend use full URL `http://localhost:3001/api/...` — no Vite proxy configured
- Theme toggle: dark-first, `.light` class on `<html>` toggles vars; FODT prevented with inline `<script>` in root.tsx `<head>`; smooth transitions via `.theme-transitioning` CSS class applied briefly; theme stored in `localStorage.getItem("theme")`
- Layout route: use `layout("routes/layout.tsx", [...children])` in routes.ts — `layout` is exported from `@react-router/dev/routes`
- Sheet/Drawer component: built from @radix-ui/react-dialog primitives in src/components/ui/sheet.tsx — no shadcn CLI needed
- Type colors: CSS custom properties in src/styles/type-colors.css as RGB triplets (`--type-fire: 240 128 48`) for alpha composability (`rgb(var(--type-fire) / 0.2)`)
- Sidebar collapse state persisted to localStorage key `"sidebar-collapsed"` — read on init with `localStorage.getItem()`
- `data-[state=open]` / `data-[state=closed]` Tailwind variants work in v4 for Radix dialog transitions
- Scripts use relative imports (`../src/lib/schemas`) NOT `~/` aliases — tsx resolves tsconfig paths but relative is more reliable in script context
- data/*.json is in .gitignore; scripts call mkdirSync("./data", { recursive: true }) to ensure the directory exists at runtime
- Item type lives in src/types/item.ts; standalone Move type in src/types/move.ts (separate from LearnableMove in pokemon.ts)
- itemSchema and moveSchema exported from src/lib/schemas.ts; itemCategorySchema and moveCategorySchema are local const reuse within the file
- DB client: @libsql/client with `file:./data/cobblemon.db` for local dev — no auth token needed for file: URLs
- Schema applied by splitting schema.sql on `;` and executing each statement; INSERT OR REPLACE used for idempotent seeding
- Nested data (types, baseStats, abilities, moves, etc.) stored as JSON strings in SQLite TEXT columns
- Scripts exit gracefully (code 0) when datapack isn't present — produce empty valid JSON arrays
- React Router v7 framework mode (SPA): requires `ssr: false` in react-router.config.ts and `@react-router/node` package
- tsconfig MUST include `"rootDirs": [".", "./.react-router/types"]` for generated types to resolve
- tsconfig needs `"allowImportingTsExtensions": true` and `"noEmit": true` in bundler/RR7 mode
- Tailwind v4 setup: use `@tailwindcss/vite` plugin + `@import "tailwindcss"` in CSS (no tailwind.config.ts needed)
- Route files use `$param` convention (not `[param]`): `$id.tsx`, `$slug.tsx`
- App directory is `src/app` (configured in react-router.config.ts), routes in `src/app/routes/`
- `src/app/routes.ts` file required — use `index()` and `route()` helpers from `@react-router/dev/routes` (no `flatRoutes`)
- `~/*` path alias maps to `./src/*` via tsconfig paths
- Types in `src/types/` (pokemon.ts, spawn.ts, team.ts); Zod schemas in `src/lib/schemas.ts`; constants in `src/lib/constants.ts`
- Zod enums from const arrays: cast with `as [string, ...string[]]` then further cast to `z.ZodEnum<[...]>` for type safety
- PokemonType tuple `[PokemonType] | [PokemonType, PokemonType]` — use `z.union([z.tuple([...]), z.tuple([..., ...])])`
- Hono server uses `@hono/node-server` serve() for tsx/Node; route order matters — specific paths (/search) before params (/:id)
- SQLite TEXT columns (types, base_stats, etc.) stored as JSON strings — parse with JSON.parse() in row-mapping helpers
