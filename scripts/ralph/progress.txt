## Codebase Patterns
- React Router v7 framework mode (SPA): requires `ssr: false` in react-router.config.ts and `@react-router/node` package
- tsconfig MUST include `"rootDirs": [".", "./.react-router/types"]` for generated types to resolve
- tsconfig needs `"allowImportingTsExtensions": true` and `"noEmit": true` in bundler/RR7 mode
- Tailwind v4 setup: use `@tailwindcss/vite` plugin + `@import "tailwindcss"` in CSS (no tailwind.config.ts needed)
- Route files use `$param` convention (not `[param]`): `$id.tsx`, `$slug.tsx`
- App directory is `src/app` (configured in react-router.config.ts), routes in `src/app/routes/`
- `src/app/routes.ts` file required — use `index()` and `route()` helpers from `@react-router/dev/routes` (no `flatRoutes`)
- `~/*` path alias maps to `./src/*` via tsconfig paths
- Types in `src/types/` (pokemon.ts, spawn.ts, team.ts); Zod schemas in `src/lib/schemas.ts`; constants in `src/lib/constants.ts`
- Zod enums from const arrays: cast with `as [string, ...string[]]` then further cast to `z.ZodEnum<[...]>` for type safety
- PokemonType tuple `[PokemonType] | [PokemonType, PokemonType]` — use `z.union([z.tuple([...]), z.tuple([..., ...])])`
